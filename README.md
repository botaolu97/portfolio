# Botao Portfolio

Personal portfolio site for Botao.

## Structure

- `index.html` - home page
- `projects/` - project detail pages
- `assets/visuals/` - logos, icons, and project imagery
- `styles.css` - shared styling

## Local Preview

Open `index.html` directly in a browser, or run a simple local server from this folder.

## Deployment

This is a static site and can be deployed to GitHub Pages, Netlify, or Vercel.
